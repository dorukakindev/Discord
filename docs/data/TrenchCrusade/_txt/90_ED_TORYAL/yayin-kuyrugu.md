# Yayın Kuyruğu — Süreç

## Akış
`taslak-kuyrugu` (ONAYLANDI) → **bu kanalda yayın planı** → ana koleksiyon forumuna taşıma → `YAYINLANDI` etiketi

## Yayın Kontrol Listesi
- [ ] Başlık EN—TR formunda
- [ ] Meta satırları dolu (Tür / Bağlılık / Kanon Sınıfı)
- [ ] Gövde `## Kayıt` başlıklı, paraphrase, ≤3 paragraf
- [ ] Kaynaklar satırı tier-1'e işaret ediyor
- [ ] Çapraz bağlantılar canlı kanal ID'leriyle (`<#id>`)
- [ ] Görsel varsa fandom thumbnail, yoksa yoktur — 'şimdilik görsel' yok

## Kurallar
- Boş bir forum için minimum **2 kayıt** beklenir — 'tek kayıtlı forum' son çaredir.
- Sözlük maddeleri farklıdır: tanım + ayrım listesi, uzun hikâye yok.
- Kayıt sonrası `a-z-indeks` ve `istatistikler` güncellenir.
