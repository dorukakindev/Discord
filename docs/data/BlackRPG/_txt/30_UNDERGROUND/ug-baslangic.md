# Underground — Başlangıç

"It's 2021 and the Dream is Dead" — satirik süper-asker distopyası.

- **Tür:** Sistem / evren girişi
- **Kaynak Sınıfı:** A (Mayfair 1993 core)

## Ne?

Ray Winninger'ın 1993 Mayfair oyunu: genetik olarak güçlendirilmiş ("boosted") paralı asker gazileri, kurumsal savaşlardan dönüp kendilerini toplumun dışlanmışı olarak bulurlar. VR'de dört-renk süper kahraman simülasyonuyla koşullandırılmış, gerçekte acımasız kiralık katiller. Oyuncular bu eski "Boost"ları oynar — işsiz, travmalı, tehlikeli.

## Okuma Rotası
- `ug-world-of-2021` → dünya durumu
- `ug-alternative-america` → siyasi harita
- `ug-veterans` + `ug-genetic-enhancements` → Boost programı
- `ug-los-angeles` / `ug-democracy-city` / `ug-luna` → mekânlar
- `ug-corporations` → patronlar

## Ton
Marshal Law + Marvelman + Aeon Flux etkisi: sinik, şiddetli, politik satir. MEGS (Mayfair Exponential Game System) varyantı kullanır.
