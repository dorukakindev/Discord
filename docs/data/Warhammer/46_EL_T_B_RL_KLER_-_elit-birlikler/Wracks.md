# Wracks
*Haemonculus'un beden-işçisi köleleri*



- **Kategori:** Birlik
- **Fraksiyon:** Drukhari
- **Dönem:** Sürekli
- **Köken:** Commorragh laboratuvarları
- **Önemli Olaylar:** Haemonculus deneylerinde silah-araç

## Tarihçe

Wracks, Haemonculus'ların elindeki sarsılmış-ameliyatlı köle savaşçılar; usta Coven'in şaheseri hizmet bedenleri. 'Ham madde' olarak gördükleri yaşayan aletler — acıya alışmışlardır.
