# Bio-Titan

Bio-Titan, Titan boyutundaki devasa Tyranid organizmalarına verilen genel addır: Hierodule, Dominatrix, Harridan ve benzeri.

- **Kategori:** Sınıf kaydı
- **Fraksiyon:** Tyranids
- **Dönem:** Sürekli
- **Köken:** Titan sınıfı Tyranid organizmaları için genel terim
- **Teknik / Biyolojik Özellikler:** Hierodule, Dominatrix, Harridan gibi dev canlılar; İmparatorluk Titanlarına karşılık gelen kategori.
- **Bilinen Kullanıcılar / Operatörler:** En büyük istila dalgaları
- **Önemli Olaylar:** Titan düzeyi tüm Tyranid çatışmaları.

## Tarihçe

Bio-Titan, Titan boyutundaki devasa Tyranid organizmalarına verilen genel addır: Hierodule, Dominatrix, Harridan ve benzeri. Bir Bio-Titan'ın gelmesi, savaşın artık orduların değil efsanelerin dövüştüğü aşamaya geçtiğini gösterir; İmparatorluk'un cevabı genelde Titan Legion'dır.
