# Maleceptor

*Zihin Kırıcı*

Yaşayan psişik top; Zealot-throne taşıyan, Shadow in the Warp'ı doğrudan savaş alanına taşıyan Tyranid psişik canavarı.

- **Kategori:** Psişik biyofor
- **Fraksiyon:** Tyranids
- **Dönem:** M41 — Leviathan dalgaları
- **Köken:** Hive Mind'ın doğrudan iradesini taşımak için evrilmiş
- **Teknik / Biyolojik Özellikler:** Açık kafasında psişik enerji yumurtası taşır; Shadow in the Warp'ı savaş alanına taşıyan yaşayan psişik batarya.
- **Bilinen Kullanıcılar / Operatörler:** Leviathan psişik şok birlikleri
- **Önemli Olaylar:** Astropath katliamları ve dünya çapı 'gölge sessizliği' vakaları.

## Tarihçe

Maleceptor, Hive Mind'ın iradesini saf psişik güç hâlinde taşıyan canlı bir odadır. Gezegenleri Shadow in the Warp'ın donmuş sessizliğine gömmede kullanılır — astropatların kafası patlar, Navigator'lar kör olur, sıradan insanlar delirir. Fiziksel olarak da tehlikelidir: üç dev gözüyle psişik şimşek çakar.
