# Umbra

Karanlık gölgeler olarak yaşayan, zihinleri işgal eden Warp-benzeri xeno varlıkları; İmparatorluk için 'yaşayan kâbus' sınıfı.

- **Kategori:** Xenos varlığı
- **Fraksiyon:** Bağımsız
- **Dönem:** Kayıt dışı
- **Köken:** Bilinmiyor; karanlık zirveli dünyalar
- **Teknik / Biyolojik Özellikler:** Bedensiz, gölge formunda var olan organizmalar; zihinleri işgal ederek beslenirler.
- **Bilinen Kullanıcılar / Operatörler:** Kovan dünyaları (gizli)
- **Önemli Olaylar:** Gözlenen tek kovan dünyası kaydı; zihin işgali vakaları.

## Tarihçe

Umbra'lar, yıldız ışığında gölgeler hâlinde var olan xeno organizmalardır: bedensiz, zihinleri yiyerek büyüyen ve Warp'tan gelmeyen ama Warp'ı andıran varlıklar. Bir Umbra güçlü psişik enerji bulduğunda zihinleri ele geçirir ve konaklarını deliliğe sürükler. Kayıtlar onları İmparator'un bile çekindiği varlıklar arasında anar.
