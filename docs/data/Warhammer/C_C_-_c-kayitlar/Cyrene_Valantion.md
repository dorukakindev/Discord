# Cyrene Valantion

*İmparatorluk'un 'Aziz Yapımcısı' — Living Saint'lerle çalışan Inquisitor*

- **Kategori:** Karakter
- **Fraksiyon:** İmparatorluk — Inquisition
- **Dönem:** M41
- **Önemli Olaylar:** Saint Sabbat araştırması

## Başlangıç
Cyrene Valantion — Word Bearers'ın 'ilk' Imperium kurbanlarından ve *The First Heretic*'in en dokunaklı figürüdür; Monarchia'da İmparator'un yıktığı şehrin 'ilk sünnetli' genç kızı, sonradan Lorgar'ın 'ilk vaftiz edilmiş' takipçisi oldu. Argel Tal'la olan bağı 'ilk iblis'in 'ilk insanı' mitosunu kurar — onun ölümü Argel Tal'ın düşüşünü hızlandırdı.
