# K'nib

K'thaktos sisteminin eski, pençeli xeno istilacıları; Festering Damnation kuşatmasıyla ünlü 'on kollu' savaşçılar.

- **Kategori:** Xenos türü
- **Fraksiyon:** Bağımsız
- **Dönem:** M41
- **Köken:** Askellon Sektörü, K'thaktos sistemi
- **Teknik / Biyolojik Özellikler:** Çok sayıda eklemli uzuvlarıyla 'on kollu' istilacılar olarak anılır; biyolojik silah doktrini kullanırlar.
- **Bilinen Kullanıcılar / Operatörler:** İstilacı savaş bantları
- **Önemli Olaylar:** Jerulas Sistemi'nde Deathwatch ile çatışma; Festering Damnation saldırıları.

## Tarihçe

K'nib'ler, Askellon Sektörü'nde bilinen eski bir xeno tehdididir. 'Festering Damnation' adı verilen saldırılarında virüs benzeri bir doktrin kullanırlar: ani yıkım yerine hedefi yavaş yavaş tüketen biyolojik silahlar. Deathwatch kayıtlarında onlarla karşılaşan ekiplerin büyük kayıplar verdiği geçer.
