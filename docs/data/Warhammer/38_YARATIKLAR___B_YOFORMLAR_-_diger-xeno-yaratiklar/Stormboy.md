# Stormboy

Rokkit pack taşıyan disiplinli-genç Ork'lar; Orkların ironik 'düzenli birlik' denemesi — sırtlarında roket, kalplerinde isyan.

- **Kategori:** Saldırı birimi
- **Fraksiyon:** Orks
- **Dönem:** Sürekli
- **Köken:** Ork ordularının 'disiplinli' gençleri
- **Teknik / Biyolojik Özellikler:** Rokkit pack taşıyan atlama birlikleri; formasyonda uçmayı seven ironik 'düzenli' Ork'lar.
- **Bilinen Kullanıcılar / Operatörler:** Stormboy mobs; hava indirme saldırıları
- **Önemli Olaylar:** Cephe gerisine çöken sürpriz baskınlar; cephane depoları ve komuta merkezlerine dalışlar.

## Tarihçe

Stormboy'lar, sırtlarına bağlanmış rokkit pack'lerle göğe fırlayan genç Ork'lardır; ironik biçimde Orklar arasında 'disiplin meraklıları' sayılırlar çünkü formasyonda uçmayı severler. Savaşta düşman hatlarının üstünden atlarlar; ama rokkit'ler güvenilmezdir ve birçok Stormboy gökyüzünden düşerek şanlı bir düşüş yaşar.
