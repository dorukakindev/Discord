# Scholastica Psykana

*Psişik Yetimhanesi*

Astropath ve Sanctioned Psyker yetiştiren İmparatorluk kurumu; Black Ships'ten gelen çocukların eğitildiği yer.

- **Kategori:** İmparatorluk kurumu
- **Fraksiyon:** Imperium — Adeptus Astra Telepathica
- **Dönem:** M31'den beri
- **Köken:** Terra; Black Ships sisteminin eğitim kolu
- **Teknik / Biyolojik Özellikler:** Astropath ve Sanctioned Psyker yetiştirir; 'sanctioned' damgası veren veya Golden Throne'a kurban ayıklayan kurum.
- **Bilinen Kullanıcılar / Operatörler:** Astra Telepathica kadroları; Inquisition ve Guard psyker'ları
