# Hive Fleet Kraken

*Kraken Filosu*

İkinci Tyrannic War'ı açan dev filo; parçalı, çok-kollu saldırı doktriniyle galaksiyi kuşatan 'yüz kol'.

- **Kategori:** Tyranid filosu
- **Fraksiyon:** Tyranids
- **Dönem:** 993.M41
- **Köken:** Galaksinin güneydoğu ucundan giriş
- **Teknik / Biyolojik Özellikler:** Tek darbe yerine yüzlerce bağımsız kol hâlinde yayılan 'çok-kollu' doktrin; her kol ayrı avlanır, öğrenir ve çoğalır.
- **Bilinen Kullanıcılar / Operatörler:** Kraken kol filolari; Genestealer kültleri
- **Önemli Olaylar:** Second Tyrannic War; Iyanden'in neredeyse yutulması; Prens Yriel'in dönüşü.

## Tarihçe

Hive Fleet Kraken, Second Tyrannic War'ın baş aktörüdür: Behemoth'un aksine tek darbe yerine yüzlerce küçük kol hâlinde yayılır. Iyanden craftworld'ü neredeyse yok eden oydu; Eldar ancak sürgün Prens Yriel'in son anda filosuyla dönüşüyle kurtuldu. Kraken resmen 'öldürülmedi' — dağıtıldı; kalıntıları bugün bile galaksinin karanlık köşelerinde aktiftir.
