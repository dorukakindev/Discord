# Lho

Tütün benzeri yasal keyif maddesi; lho-stick olarak içilir. Astra Militarum siperlerinde yaygındır.

- **Kategori:** Terim
- **Sınıf:** Günlük yaşam
- **Kanon Sınıfı:** A — resmî kaynak

## Tarihçe

İmparatorluk'un yaygın sigarası; hafif narkotik bitki özü içeren rulo tüp. Astra Militarum neferinin ve işçinin ortak tesellisi — cephedeki 'beş dakikalık barış'.
