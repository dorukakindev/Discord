# Osiris
> **Mitoloji:** Mısır · **Tür:** tanri · **Eş:** İsis
*Set tarafından öldürülen, İsis tarafından diriltilen; ölülerin yargıcı ve dirilişin simgesi.*

Osiris Mısır'a medeniyeti, tarımı ve yasaları getirdi. Kıskanç kardeşi Set onu öldürüp parçalara böldü. İsis parçaları toplayarak onu diriltti; Horus'u doğurdu. Ölüler dünyasının hakimi oldu.

### Lakaplar
- Ölüler Tanrısı
- Yeniden Dirilen
- Mısır Medeniyetinin Getireni
