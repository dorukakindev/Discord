# Erken İtalya: oyun kanıtı, okült iddia değil
> **Dönem:** 1440-1450ler · **Uyarı:** 15. yüzyıl kartlarını doğrudan modern RWS fal anlamlarıyla eşitleme. · **Güven:** Yüksek: müze sergi metni ve ansiklopediyle çapraz kontrol edildi.
