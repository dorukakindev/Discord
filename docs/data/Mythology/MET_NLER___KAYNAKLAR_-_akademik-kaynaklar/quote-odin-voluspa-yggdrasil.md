# quote-odin-voluspa-yggdrasil
> **Sourceid:** poetic-edda · **Kaynak:** Poetic Edda, Völuspá / Hávamál geleneği · **Reference:** Hávamál 138-141 çevresi · **Dil:** tr

Odin kendini ağaca astı; bilginin bedeli beden, zaman ve sessizlik oldu.

### Not
Odin’in kendini kurban ederek runik bilgiye ulaşması motifini bağlar.

### Motifler
