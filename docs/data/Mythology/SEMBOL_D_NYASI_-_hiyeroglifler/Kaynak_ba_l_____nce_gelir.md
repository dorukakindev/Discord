# Kaynak başlığı önce gelir
> **Durum:** Bir yazıt, fotoğraf veya kullanıcı metni çevrilmeden önce kimlik bilgisi eksikse. · **Notasyon:** object -> script -> direction -> line/column -> confidence · **Çıktı Kalıbı:** Kaynak: ... | Script: ... | Yön: ... | Satır: ... | Güven: ... | Eksik kanıt: ... · **Risk:** Kaynak başlığı olmadan üretilen akıcı çeviri, hiyeroglif metni değil modern tahmin olabilir.

### Adımlar
- Nesne veya metin taşıyıcısını yaz: müze envanteri, tapınak duvarı, papirüs, ostrakon, stel veya modern görsel.
- Script türünü ayır: hiyeroglif, kursif hiyeroglif, hiyeratik, demotik, Kıpti veya modern font.
- Okuma yönü ve satır/sütun bilgisini ayrı not et; çeviriye başlamadan önce metadata boşluklarını listele.
- Kullanıcıya ilk çıktıda 'bu bir nesne teşhisi mi, işaret kimliği mi, transliterasyon mu, çeviri mi?' ayrımını göster.

### Kanıtlar
- Müze/korpus kaydı
- Fotoğraf veya facsimile
- Satır/sütun konumu
- Tarih/dönem aralığı
