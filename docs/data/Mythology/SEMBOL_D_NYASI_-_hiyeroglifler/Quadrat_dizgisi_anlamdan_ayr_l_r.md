# Quadrat dizgisi anlamdan ayrılır
> **Durum:** İşaretlerin üst-alt/yan yana düzeni, Unicode format kontrolü veya JSesh/MdC dizgisi sorulursa. · **Notasyon:** horizontal / vertical / overlay / insert / cartouche · **Çıktı Kalıbı:** Dizgi: ... | Dijital temsil: ... | Filolojik okuma: ... | Uyarı: ... · **Risk:** Quatrat içindeki her görsel parçayı sırayla harf gibi okumak.

### Adımlar
- Dizgiyi önce görsel yerleşim olarak tarif et: yatay, dikey, üst üste, iç içe veya kartuş içinde.
- Dizgi kontrolünün gramer veya kelime anlamı olmadığını özellikle söyle.
- Bileşik işaret logogram olabilir; parçaların tek tek ses değeri her zaman bileşiğin anlamı değildir.
- Eğer amaç dijital yazım ise JSesh/MdC; amaç filolojik okuma ise korpus/edisyon rotasına yönel.

### Kanıtlar
- JSesh/MdC kodu
- Unicode format karakterleri
- Gerçek nesne görüntüsü
- Korpus okuması
