# prt-ḫrw
> **Translation:** Sesle çıkan sunu / invocation offering · **Context:** Ölü adına okunarak etkinleşen ekmek, bira, öküz, kuş, giysi, tütsü ve benzeri sunu listelerinde görünür. · **Grammar:** prt çıkma/ortaya çıkma alanı; ḫrw ses/söz alanı taşır. Formül, sununun ritüel sözle çağrılmasını vurgular. · **Uyarı:** Sadece fiziksel yiyecek listesi değildir; okunan söz, sununun öteki dünya ekonomisindeki etkinlik mekanizmasıdır.
