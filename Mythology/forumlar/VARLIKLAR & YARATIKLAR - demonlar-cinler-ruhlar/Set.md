# Set
> **Rütbe:** Tanrısal · **Köken:** Mısır · **Tür:** demon

Çöl, fırtına, kaos ve yabancılığın Mısır tanrısı; Osiris'i parçalayan ve Horus'un düşmanı olan kuvvet.

### Diğer Adlar
- Sutekh

### Arka Plan

Set (Seth), Mısır'ın çöl-fırtına tanrısı: Osiris'i öldürüp parçalayan kardeş; Horus'la 80 yıl süren taht kavgası. 'Kırmızı saçlılar' ona adanır; ama aynı zamanda güneş barkında Apep'e karşı savaşan ön-savunmacı. 'Kötü ama gerekli' figür — düzen için kaos gücü; İsis'in kaçamak aşkı (bazı varyantlarda babası) olarak da karmaşık aile hattı.
