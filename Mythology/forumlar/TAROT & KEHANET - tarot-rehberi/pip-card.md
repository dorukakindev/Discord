# pip-card
> **Term:** Pip / numeral kart · **Kategori:** yapı · **Uyarı:** Marseille pip kartlarına RWS sahnesini zorla yapıştırma.

### Kullanım
RWS dışı destelerde sahneli anlam ezberi yerine suit-sayı ritmine dön.
