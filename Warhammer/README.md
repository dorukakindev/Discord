# The Imperial Archive — Warhammer 40,000

Bu klasör, Discord sunucusu **The Imperial Archive**'ın (Türkçe WH40k A–Z ansiklopedisi) tam içerik dökümüdür.

## Yapı

- `forumlar/<Kategori> - <forum-adı>/<Kayıt Adı>.md` — her forum postu bir markdown dosyası (2026 kayıt, 96 forum)
- `metin-kanallari/<kategori>/<kanal>.md` — metin kanallarının içeriği (baslangic, kurallar, a-z-indeks, istatistikler vb.)
- `../server_manifest.json` — roller, kategoriler, kanallar ve forum başına kayıt listesi (tam envanter)

## Format

Her kayıt kanonik kart yapısındadır:

```
-# THE IMPERIAL ARCHIVE · <Bölüm> · Kayıt
# <Başlık>
<tanım paragrafı>
- **Kategori:** ...
- **Fraksiyon:** ...
- **Dönem:** ...
- **Köken:** ...
## Tarihçe / İçerik / Teknik ve Kullanım ...
-# Kaynaklar: ...
-# İlişkili kayıtlar: ...
```

## Kapsam

- 26 harf kaydı forumu (A–Z, ~500 kayıt)
- 67 koleksiyon forumu (bölükler, araçlar, silahlar, karakterler, olaylar, varlıklar, organizasyonlar...)
- 3 roman forumu (Horus Heresy 54 cilt, Siege of Terra 9 cilt, diğer romanlar)
- ~2.030 kayıt toplamı
